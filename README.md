# Minor-Project-03-SkyPulse-Cineflix
# 🌤️ SkyPulse × 🎬 Cineflix
### Minor Project 03 – Weather App & Movie Search App

A responsive web development project featuring two interactive applications: **SkyPulse**, a real-time weather forecasting application, and **Cineflix**, a movie discovery and search platform.

Built using HTML5, CSS3, JavaScript (ES6+) and public REST APIs.

---

## 📌 Project Overview

This project demonstrates how modern web applications fetch, process and display real-time information using APIs. It combines weather forecasting with movie discovery in one responsive website.

## 🌤️ 1. SkyPulse – Weather Application

SkyPulse helps users check weather conditions for different cities.

### Features
- Search weather by city name.
- Display current temperature.
- Show weather conditions such as sunny, cloudy, rainy and thunderstorms.
- Display humidity and wind speed.
- Show precipitation information.
- Five-day weather forecast.
- Daily temperature highs and lows.
- Rain probability.
- Option to use the current location.
- Error handling for invalid city searches.
- Dark-themed responsive interface.

**API Used:** [Open-Meteo](https://open-meteo.com/)

## 🎬 2. Cineflix – Movie Search Application

Cineflix is a movie discovery platform inspired by popular streaming interfaces.

### Features
- Search for movies by title.
- Display movie posters.
- Show movie ratings and release years.
- Display movie descriptions.
- Browse different movie categories:
  - English
  - Hindi
  - Bengali
  - Cartoon
- Filter movies by genre.
- Add movie reviews and comments.
- Subscription-style viewing preview.
- Official trailer search links.
- Responsive Netflix-inspired design.

**API Used:** [OMDb API](https://www.omdbapi.com/)

Sample movies are included. A free OMDb API key is required to enable additional live movie searches.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Extract the downloaded files if necessary.
3. Open the project folder in Visual Studio Code.
4. Install the Live Server extension.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. The application will open in your browser.

**Note:** Run the project through a local development server because JavaScript ES modules are used.

## 🔑 API Configuration

### Weather API
SkyPulse uses Open-Meteo, which does not require an API key.

### Movie API
To enable live movie searches:

1. Visit [OMDb API](https://www.omdbapi.com/apikey.aspx).
2. Request a free API key.
3. Open `config.js`.
4. Replace `YOUR_OMDB_API_KEY` with your API key.
5. Save the file and refresh the website.

```javascript
window.APP_CONFIG = {
    OMDB_API_KEY: "YOUR_API_KEY"
};
```

## 🌐 Deployment

The project can be hosted using GitHub Pages.

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch.
5. Select the `/ (root)` folder.
6. Click **Save**.

Your website will be available through the GitHub Pages URL generated by GitHub.
